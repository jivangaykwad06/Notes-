📚 NoteVault

A simple and modern study notes website.

✨ Features

- 📱 Mobile responsive
- 🎨 Modern UI
- ✨ Smooth animations
- 🔍 Search notes
- 📚 Subject-wise notes
- 📄 PDF & image notes
- 🌙 Dark mode
- ❤️ Favorite notes

🛠️ Built With

- HTML
- CSS
- JavaScript

🌐 Hosting

Hosted using GitHub Pages.

📌 Note

This is a frontend project using browser storage. It does not use PHP, MySQL, or any backend.
